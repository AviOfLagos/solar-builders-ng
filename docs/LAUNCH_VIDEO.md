## 4. Motion direction

- **Style:** 2D motion graphics over a mix of shot-on-phone footage; UI in a flat phone frame. Brand palette above.
- **Easing:** `cubic-bezier(0.22, 1, 0.36, 1)` for entrances; `cubic-bezier(0.4, 0, 1, 1)` for exits.
- **Durations:** text in 300–400 ms, UI transitions 250–350 ms, progress bar fill 1.2s with ease-out; stagger names 120 ms apart.
- **Cut rhythm:** a cut every 2–3s in the problem, slower (3–4s) in the solution so the UI reads.
- **Type:** minimum 48px at 1080p for captions, max two lines, bottom-third safe zone. Mint chip behind keywords.
- **Sound:** generator hum fades out at 0:28 as the bar fills; soft rising pad; one clean click on each contribution. VO dry and warm, Nigerian English voice. Mix target -14 LUFS integrated, VO peaks -3 dBTP.
- **Colour:** problem scenes desaturated and cooler; after-state warm with mint. Flare red only for the petrol counter.
